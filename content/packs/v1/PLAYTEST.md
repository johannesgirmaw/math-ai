# Version 1 playtest

Beachhead: teens and adults, about 14 to 35, curious about AI. Each session is a think-aloud on the first dot-agreement lesson, on a phone build. These notes are the protocol and the release checklist. Live sessions have not been run yet, so this file does not invent what a person said or where they stalled.

## Product acceptance

- [x] Sign-up, a 5-minute goal, placement, the path, and mission complete are wired. Streak comes from the complete response.
- [x] Grading runs on the device from the shared fixture file. A cached lesson can open when requests fail, and a queued result posts once.
- [x] Publishing runs the cycle check and names the node ids in `CycleError`.
- [x] Marketing and admin use the paper, ink, and accent tokens.
- [x] A Good rating schedules `dueAt` after the completion timestamp.
- [x] `/design` is not found in production. `/api/v1/docs` is not mounted.
